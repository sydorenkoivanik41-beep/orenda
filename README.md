# Оренда без ріелторів

Сайт: https://sydorenkoivanik41-beep.github.io/orenda/

Збирає оголошення про оренду квартир від власників з OLX.ua та LUN, оновлюється автоматично кожні ~3 години.

- Додати місто: відкрийте `settings.ini` → олівець ✏️ → додайте рядок у розділ `[міста]`, напр. `Вінниця = vinnitsa` (останнє слово з адреси сторінки оренди на OLX) → Commit changes.
- Слова-фільтри ріелторів: `stop_words.txt` (ховає), `doubt_words.txt` («Сумнівно»), `allow_phrases.txt` (винятки).
- Запустити оновлення вручну: вкладка Actions → «Оновлення оголошень» → Run workflow.
